# Ahbe123

## Messenger Workspace Persian Edition

این شاخه شامل پروژه دسکتاپ Windows با نام **Messenger Workspace Persian Edition** است.

مسیر پروژه:

```text
MessengerWorkspace/
```

راهنمای کامل فارسی، روش Build، وابستگی‌ها و راهنمای نصب در فایل زیر قرار دارد:

```text
MessengerWorkspace/README-fa.md
```

خروجی مورد انتظار پس از Build ویندوزی:

```text
MessengerWorkspace/dist/MessengerWorkspace.exe
MessengerWorkspace/dist/MessengerWorkspaceSetup.exe
```
