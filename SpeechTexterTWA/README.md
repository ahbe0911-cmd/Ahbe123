# تایپ صوتی — SpeechTexter Hybrid 2.0

نسخه اندروید فارسی و راست‌چین SpeechTexter که یک موتور تایپ صوتی بومی و پایدار را در کنار TWA سایت \`https://www.speechtexter.com/\` نگه می‌دارد.

## امکانات نسخه ۲

- تشخیص گفتار بومی فارسی و انگلیسی با نتایج موقت
- کپی خودکار فقط پس از دریافت نتیجه نهایی
- حالت تایپ پیوسته با کنترل خطا، سکوت و درخواست تکراری
- فرمان‌های گفتاری برای نقطه، ویرگول، سؤال، تعجب و خط جدید
- ویرایش متن، شمارش کلمه و نویسه
- ذخیره دائمی پیش‌نویس با نوشتن تأخیری و کم‌هزینه
- تاریخچه محلی SQLite، جستجو، بازکردن، کپی و حذف
- خروجی استاندارد UTF-8 در TXT و PDF چندصفحه‌ای
- اشتراک‌گذاری متن با برنامه‌های نصب‌شده
- رابط فارسی RTL، فونت Vazirmatn و تم روشن/تیره
- دسترسی مستقیم به سایت اصلی با لانچر TWA ضدکرش

## مشخصات فنی

- Android 8.0 به بالا (\`minSdk 26\`)
- \`compileSdk/targetSdk 36\`
- Android Browser Helper \`2.7.3\`
- AndroidX Browser \`1.10.0\`
- AndroidX AppCompat \`1.7.1\`
- فقط HTTPS؛ ترافیک Cleartext غیرفعال است
- بدون مجوز گسترده فایل؛ خروجی‌ها با Document Provider خود اندروید ذخیره می‌شوند
- ساخت Release با R8 و حذف منابع بلااستفاده

## حریم خصوصی

متن پیش‌نویس، تنظیمات و تاریخچه فقط در فضای خصوصی همین برنامه ذخیره می‌شوند. برنامه فایل صوتی ضبط یا نگه‌داری نمی‌کند. صدای میکروفون توسط سرویس تشخیص گفتار نصب‌شده روی دستگاه پردازش می‌شود؛ بسته به سرویس انتخابی کاربر، این پردازش ممکن است به اینترنت نیاز داشته باشد. پاک‌کردن داده‌های برنامه، اطلاعات محلی را حذف می‌کند.

## نکته درباره TWA

مالک این پروژه به سرور \`speechtexter.com\` دسترسی ندارد. برای حذف کامل نوار مرورگر، مالک دامنه باید فایل Digital Asset Links را با اثرانگشت گواهی APK در مسیر زیر منتشر کند:

\`https://www.speechtexter.com/.well-known/assetlinks.json\`

تا آن زمان Android Browser Helper به‌صورت امن از Custom Tab استفاده می‌کند. موتور بومی صفحه اصلی مستقل از این تأیید دامنه کار می‌کند.

## ساخت و کنترل کیفیت

\`\`\`bash
./gradlew clean check lintRelease assembleDebug assembleRelease
\`\`\`

APK دیباگ در \`app/build/outputs/apk/debug/app-debug.apk\` و Release بدون امضا در \`app/build/outputs/apk/release/app-release-unsigned.apk\` ساخته می‌شود. نسخه Release باید با کلید مالک برنامه امضا شود.

## مالکیت

این پروژه مستقل است و وابستگی یا نمایندگی رسمی از SpeechTexter ندارد. برای انتشار عمومی یا فروشگاهی باید مجوز استفاده از نام و محتوای سرویس بررسی شود.
